1. What Wavenum does

Wavenum is a workbench for Raman, FTIR and XRD data. It loads spectra and diffraction patterns from common instrument and text formats, corrects them with a non-destructive processing pipeline, finds and fits peaks, identifies minerals against reference libraries, and analyses whole maps. It was written for meteorites and rocks but also covers pigments, polymers and other materials in the bundled libraries.

On your own computer (desktop app, or the web app started locally) your data never leave the machine. The public website is a demonstration: data you load there are sent to its server for processing (see section 18).

The header shows, for the technique you have selected, how many reference spectra, distinct phase names and libraries Wavenum is currently searching. Hover over it for details. Section 12 lists where every library comes from.

2. Getting started

  1. Choose the technique in the header: Raman, XRD or FTIR. Each technique keeps its own spectra, axis labels and libraries.
  2. Drop files onto the box at the top left, click it to browse, or pick Open an example file…. Every example has a one-line note on what it teaches.
  3. Open Preprocess to switch on despiking, baseline correction, smoothing and normalization.
  4. Open Peaks and click Find peaks, then Fit.
  5. Open Mineral ID and click Identify. Click a match to see the mirror plot of your spectrum against the reference.
  6. Export the figure with Figure export, the data with Data .csv, and save everything with Session in the sidebar.

A good first exercise: load quartz_raman.csv from the examples. It contains a fluorescence background and one cosmic-ray spike at 950 cm⁻¹; switch on Despike and Baseline, then identify it.

4. Loading data

Text tables

Wavenum detects the delimiter (comma, tab, semicolon, spaces), skips header and metadata lines (including RRUFF ##KEY=value lines) and uses the first numeric column as the x axis. If a file has several intensity columns a column picker appears: choose one, or add all of them as separate spectra. Excel workbooks (.xlsx) work the same way.

Instrument files

JCAMP-DX, Thermo SPC, Nicolet SPA, Bruker OPUS, Agilent ASP, PANalytical XRDML, Rigaku RAS, Bruker UXD and Renishaw WDF files are read directly. A .cif crystal structure is converted to a computed powder pattern (Cu Kα). Files that hold several spectra (maps, line and depth scans) load their first non-empty spectrum in the workspace; open them in the Map tab to use all of them.

Which technique?

A file is loaded into the technique selected at that moment. Switch technique before loading. FTIR spectra are shown with the wavenumber axis reversed, as usual.

Spectrum arithmetic

Under Arithmetic: average the visible spectra, or subtract one spectrum from another with a scale factor (for example to remove a mounting-medium or host-mineral contribution).

5. Preprocessing

Each spectrum has its own pipeline of steps, shown in the sidebar. The raw data are never changed: steps can be switched on and off, reordered with the arrows, removed and undone. The plot updates as you change a step.

StepWhat it doesAdvice
Crop rangeKeeps an x range.Crop first to drop detector edges or the laser line.
Cosmic-ray despikeFinds a sharp rise followed within a few points by a sharp fall (modified z-score of the first difference above the threshold) and replaces those points by a straight line.Default threshold 7. Lower it only if spikes remain; narrow real peaks are protected because both edges must be steep and isolated.
Baseline correctionALS, airPLS, iterative polynomial or rubberband. Show baseline draws the estimated background.ALS or airPLS for fluorescence in Raman; rubberband for FTIR absorbance; polynomial for gentle slopes.
SmoothingSavitzky–Golay or moving average.Use the smallest window that removes noise; heavy smoothing broadens peaks.
NormalizationMin–max, vector (unit length), area, or SNV.Normalize before comparing intensities between spectra.
Other steps (+ Add step)Derivatives, transmittance ↔ absorbance, nm → Raman shift (enter the laser wavelength), resampling, x-axis shift.Calibrate the x axis on a standard (e.g. silicon 520.7 cm⁻¹) before reading band positions.

Save a pipeline as a JSON preset and load it later, or apply it to all spectra of the technique at once.

6. Plot, curves and figures

Views

Overlay draws spectra on one axis; Stacked offsets them vertically. Zoom by dragging, double-click to reset, and use the Plotly toolbar to pan or zoom further.

Curve selector

Curves lists everything on the plot: each spectrum, the baseline, fitted sum, components, residual, the library reference and peak markers. Untick a curve to hide it; the plot and the axis range adjust immediately and the exported figure contains exactly what is shown. Show all and Hide extras are shortcuts. Clicking a legend entry does the same.

7. Peaks and fitting

Finding peaks

Set the prominence and minimum height (as fractions of the intensity range) and the minimum distance between peaks, then click Find peaks. Moving a slider re-runs the search live. Tick Manual edit to add a peak by clicking the spectrum, or remove one by clicking its marker.

Fitting

Choose Lorentzian, Gaussian or Voigt profiles and, optionally, a region. Fit fits one profile per marked peak inside the region plus a straight background. The plot shows the sum, each component and the residual; the peak table gives centre, height, FWHM, area and R². For XRD the table also gives the d-spacing (Cu Kα1). Copy the table or save it as CSV.

Overlapping peaks rarely have a unique solution. Check the residual, keep the number of peaks to what the data support, and use Monte Carlo deconvolution to see how well each parameter is constrained.

8. Monte Carlo deconvolution

Following SpecXY (Gies et al. 2024), Wavenum repeats the fit many times from random starting values: each peak starts anywhere within ± the maximum shift of where you marked it, with its width multiplied by 0.5–2 and its height by 0.5–1.5. During every run each peak may move at most ± the maximum shift. Run 1 always uses the ordinary starting values.

  1. Mark the peaks and set the fit region and profile as for a normal fit.
  2. Set Runs (2–1000) and Max. shift (axis units), then click Run.
  3. Choose which runs to keep: those with R² within 0.0001, 0.001, 0.01 or 0.05 of the best, or all.
  4. Read the mean ± standard deviation of position, FWHM, area and height for each peak (hover for the range), and inspect the histogram of any peak and parameter. All runs (.csv) saves every run.

A narrow histogram means the parameter is well constrained; a broad or multi-modal one means several solutions fit the data equally well. The best run is drawn on the plot and fills the peak table. Fitting a small region with few peaks is much faster than fitting the whole spectrum.

9. H₂O content from FTIR

For FTIR spectra the Peaks tab has an H₂O content card (SpecXY/SpecDB, Gies et al. 2024, Eq. 9). It integrates the absorbance over the band window above a straight baseline and applies the Beer–Lambert law:

If peaks have been fitted, the card also reports the water content from the summed areas of the fitted peaks inside the window, which lets you exclude bands from inclusions (as in Gies et al. 2024). The spectrum must be in absorbance with the background removed. Densities are filled in with typical values: replace them with your sample's.

On an FTIR map, the same card in the Map tab adds an H₂O map: the integrated absorbance of every pixel multiplied by the same factor.

11. Mineral identification

  1. Select the libraries to search (all are selected by default).
  2. Adjust the score weights if needed: cosine similarity (overall shape), Pearson correlation and peak matching with a shift tolerance (default 8 cm⁻¹ for Raman and FTIR).
  3. Click Identify. The search copy of the spectrum is baseline-corrected automatically, so raw spectra can be searched.
  4. Click a match to show the mirror plot (sample above, reference below) and its source and citation.

Mixture check fits the spectrum as a non-negative combination of the best match and each other candidate; fractions are spectral weights, not modal abundances. Supported by several techniques lists phases supported by spectra of more than one technique loaded for the same sample. Browse library finds a reference by mineral name or formula and overlays it. For XRD choose the X-ray tube (Cu, Co, Mo, Fe, Cr) so 2θ positions are converted correctly.

A high score is a suggestion, not proof. Confirm the main bands, check the mirror plot and the residual, and consider the geological context. Matches against small libraries are limited to the phases those libraries contain.

13. PCA

The PCA tab runs principal component analysis on the visible spectra of the current technique (interpolated to a common axis). Choose the row scaling (none or vector/L2) and, optionally, a number of k-means groups (0 = off), then click Run PCA. The scores plot shows how spectra cluster; the loadings show which bands drive each component. Labels are shortened on the plot; hover for full names. Export the scores as CSV or the plot as a figure.

The Map tab follows SpecXY's map module (Gies et al. 2024).

A value grid or image with the same size as the loaded spectral map is added as a layer of the same area, so element maps from EPMA, EDS or LA-ICP-MS can be compared pixel by pixel. Try Open an example map…: a 40 × 30 pixel Raman map of a quartz grain with a hematite inclusion in calcite, with matching SiO₂, CaO and Fe₂O₃ maps.

Map types

Every type can be multiplied by a calibration factor C and rescaled to 0–1. Colour scales, log scale and 2–98 % clipping are set per layer.

Tools

  • Click modes: pixel spectrum, region mean (two corners) and line profile (two ends). Spectra can be sent to the workspace; profiles saved as CSV.
  • Map calculator: A + − × ÷ B between layers.
  • Mask: keep pixels of a layer within a value range; other tools then use only those pixels.
  • Classes (k-means): groups pixels by spectral shape in x₁–x₂ (area-normalized). Each class mean is sent to the workspace for identification.
  • Every layer exports as CSV, and the map as a figure.

15. Digitizer

Recover a spectrum from a published figure (PNG, JPG or a PDF page):

  1. Load the image or PDF page in the Digitizer tab.
  2. Click the four calibration points in order (two on the x axis, two on the y axis) and type their values.
  3. Click the curve to pick its colour and adjust the colour tolerance: for every pixel column between the x calibration points Wavenum takes the mean position of pixels close to that colour.
  4. Check the trace, then Send to workspace. Reset points starts again.

The digitizer assumes linear axes. Accuracy depends on the image resolution; check positions against the original values.

16. Sessions and export

  • Save session (sidebar, under Arithmetic · session · export) writes a .wavenum.json file with all spectra, pipelines, peaks and figure settings; opening that file again restores it.
  • Data .csv / .txt exports the processed spectra; the peak table, Monte Carlo runs, PCA scores and map layers each have their own CSV button.
  • Figures: see section 6.

19. Troubleshooting

ProblemWhat to try
A file does not loadCheck the technique and the format list; export to text or JCAMP-DX; for text files make sure the first numeric column is the axis.
Wrong or no matchesCorrect the baseline, crop to the useful range, calibrate the axis, widen the tolerance, and check that the mineral is in the libraries (library browser).
Fit does not converge or looks wrongFit a smaller region, remove doubtful peaks, try another profile, or run Monte Carlo deconvolution.
Monte Carlo is slowUse a region with fewer peaks or fewer runs; the desktop app runs fits in parallel.
A spike survives despikingLower the threshold step by step; very broad artefacts are better removed by cropping.
Map looks scrambledChoose the right Read text as layout, and for the matrix layout enter nX and nY.

Bug reports and sample files are welcome on GitHub.
